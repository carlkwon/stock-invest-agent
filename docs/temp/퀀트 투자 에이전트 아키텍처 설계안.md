1. 핵심 아키텍처 설계 원칙 (Architectural Principles)
Stateful Graph 기반 샌드박스화 (Isolation):

각 기능 단위(데이터, 신호산출, 리스크, 주문)를 독립된 Sub-graph 및 Node로 격리하여 상태(State)의 오염을 방지합니다.

Deterministic-First, LLM-Second (결정론 우선 법칙):

백테스팅, 이동평균선/볼린저밴드 계산, 수급 조건 판정, Trailing Stop-Loss 등 모든 수치적 판단은 Python 코드로만 집행합니다.

LLM은 (1) 뉴스/공시의 정성적 리스크 감지, (2) 매매 근거 자연어 요약, (3) 예외 상황 시 Supervisor 인터럽트 처리에만 제한적으로 사용합니다.

Pydantic Strict Response Schema:

에이전트 간 주고받는 모든 메시지 및 데이터 객체는 Pydantic 기반의 Strict JSON Schema로 검증되어 타입 불일치로 인한 오작동을 원천 차단합니다.

2. 세부 서브시스템 및 노드(Node) 설계
① Data Collector Sub-graph (데이터 수집 및 정제)
Market Data Collector: KRX/한국투자증권 API 연동. OHLCV, 수정주가, 거래량, 이동평균(5, 20, 60, 120일), 볼린저밴드(%B, Bandwidth) 산출.

Flow Data Collector: 외국인, 기관 전체, 그리고 핵심 메이저 수급인 [투신 + 연기금]의 연속 순매수 수량 및 금액 데이터 집계. (단기 차익 성격의 '금융투자' 자금은 별도 분리 표기)

Data Sanitizer (검증): 결측치, 상장폐지/정지 여부, 수치 이상 유무를 사전 검증하여 이상 발생 시 DataErrorState로 분기.

② Signal Engine Node (신호 생성 및 앙상블)
Technical & Flow Ensemble Signal:

조건 A (기술적 지표): 주가가 20일선 상단 위치 + 볼린저 밴드 상단 돌파 시도 + 거래량 전일 대비 150% 이상 급증.

조건 B (수급 필터): 최근 3일 중 2일 이상 외국인 또는 (투신+연기금) 동시 순매수 우위.

결합 팩터 스코어링: 조건 성립 여부에 따라 SignalScore (0~100점)를 계산하여 상위 N개 종목 후보군 선정.

③ Risk Engine Node (강력한 리스크 방어 레이어) ★ Core Safety
Trailing Stop-Loss Engine:

보유 종목의 포지션 오픈 이후 최고가(High Water Mark) 대비 -N% 하락 시 LLM 추론을 거치지 않고 즉시 FORCE_SELL 신호발생.

Portfolio MDD & Volatility Target Engine:

일별/월별 포트폴리오 MDD가 지정된 임계치(예: -5%)에 도달하면 즉시 Kill-Switch 작동. 신규 매수 전면 동결.

LLM Qualitative Risk Analyzer (선택적):

포착된 종목에 대해 횡령, 배임, 감사의견 관련 악재 공시나 악성 뉴스가 존재하는지 텍스트 파싱 후 Risk Level(Low/Medium/High) 부여. High일 경우 매수 거부.

④ Execution & Ops Sub-graph (집행 및 모니터링)
Order Router: 한국투자증권 REST API 연동. 슬리피지(Slippage) 최소화를 위해 TWAP 분할 매수 주문 또는 장 마감 지정가/시장가 집행.

Dashboard & Sheet Sync (GAS):

매일 장 마감 후 발생한 매매 신호, 사유, 보유 포지션, MDD, 손절 라인을 Google Sheets API / Google Apps Script(GAS)와 연동하여 실시간 모니터링 대시보드 업데이터.

Notification Service: 텔레그램/슬랙 알림 봇을 통해 [신호 발생 원인 - 리스크 검증 결과 - 최종 집행 내역]을 파이프라인 형태로 사용자에게 전송.

3. LangGraph AgentState 전체 데이터 스키마
Python
from pydantic import BaseModel, Field
from typing import List, Dict, Optional
from datetime import datetime

class StockMetrics(BaseModel):
    ticker: str = Field(description="종목코드 6자리")
    stock_name: str
    close_price: float
    ma_20: float
    bollinger_upper: float
    volume_ratio: float  # 전일 대비 거래량 비율
    net_institution_buy: float  # 투신 + 연기금 순매수
    net_foreigner_buy: float

class SignalOutput(BaseModel):
    ticker: str
    signal_score: float = Field(description="0~100 팩터 결합 점수")
    action: str = Field(description="BUY, SELL, HOLD")
    target_weight: float = Field(description="포트폴리오 내 목표 비중")
    signal_reasons: List[str] = Field(description="신호 발생 원인 요약")

class RiskCheckResult(BaseModel):
    ticker: str
    is_approved: bool
    trailing_stop_price: float
    mdd_status: str
    risk_notes: Optional[str] = None

class QuantSystemState(BaseModel):
    timestamp: str = Field(default_factory=lambda: datetime.now().isoformat())
    market_phase: str = Field(description="PRE_MARKET, REGULAR, POST_MARKET")
    collected_stocks: Dict[str, StockMetrics] = {}
    generated_signals: List[SignalOutput] = []
    approved_signals: List[SignalOutput] = []
    portfolio_mdd: float = 0.0
    kill_switch_activated: bool = False
    execution_logs: List[str] = []
4. LangGraph 그래프 제어 흐름 (Graph Control Flow)
Python
# LangGraph Workflow Pseudo-Structure
from langgraph.graph import StateGraph, END

workflow = StateGraph(QuantSystemState)

# 1. 노드 등록
workflow.add_node("data_collector", data_collector_node)
workflow.add_node("signal_engine", signal_engine_node)
workflow.add_node("risk_engine", risk_engine_node)
workflow.add_node("executor", executor_node)
workflow.add_node("dashboard_sync", dashboard_sync_node)

# 2. 엣지 및 조건부 분기(Conditional Edges) 설정
workflow.set_entry_point("data_collector")
workflow.add_edge("data_collector", "signal_engine")
workflow.add_edge("signal_engine", "risk_engine")

# 리스크 체크 후 Kill-Switch 작동 여부에 따른 조건부 분기
def check_kill_switch(state: QuantSystemState):
    if state.kill_switch_activated:
        return "dashboard_sync" # 매매 취소 후 즉시 보고서 동기화로 이동
    return "executor"

workflow.add_conditional_edges(
    "risk_engine",
    check_kill_switch,
    {
        "dashboard_sync": "dashboard_sync",
        "executor": "executor"
    }
)

workflow.add_edge("executor", "dashboard_sync")
workflow.add_edge("dashboard_sync", END)

app = workflow.compile()
5. 향후 단계적 확장 전략
Sub-Agent 단위의 모듈화 개발:

데이터 수집 노드 및 팩터 산출 로직을 파이썬 모듈로 먼저 작성 후, LangGraph 상태 노드로 래핑(Wrapping).

Backtrader/Custom Engine 연동 백테스팅:

동일한 Signal Engine 및 Risk Engine 로직을 과거 3년~5년 데이터에 통과시켜 샤프 지수(Sharpe Ratio) 및 MDD 검증.

Paper Trading (모의투자 실행) & GAS 대시보드 완성:

한국투자증권 모의투자계좌 API를 연결하여 실시간 시세 데이터 기반으로 수급+지표 팩터의 실전 승률 테스트.
