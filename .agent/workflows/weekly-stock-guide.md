# 주간 투자 가이드 (Weekly Stock Guide) 통합 워크플로우

## Meta Data & Description
* **Name:** Weekly Stock Guide — Outlook, Mid-Check & Review (Unified)
* **Trigger Command:** `/weekly-guide` (요일에 따라 `{{MODE}}`를 자동 판별하되, 필요 시 `/weekly-guide MODE=OUTLOOK`처럼 명시 가능)
* **Trigger Timing:** 일요일(`OUTLOOK`) / 수요일(`MIDCHECK`) / 금요일(`REVIEW`) — 주 3회 실행되지만 **매번 같은 리포트 파일 하나**를 이어서 갱신한다.
* **Description:** 종목별 매수/매도/관망 가이드를 일요일에 작성하고(목표가·손절가·확신도·예상 결판 시점 포함), 수요일에는 새 종목 스크리닝 없이 기존 종목의 조기 도달·손절 근접 여부만 경량 점검하며, 금요일에는 실제 주가와 대조해 적중/실패를 정량 판정한다. 세 단계가 파일 하나(`weekly_guide_{{TARGET_WEEK_START}}.md`)에 순서대로 쌓여, 한 주의 판단→중간 점검→결과가 한눈에 이어져 보인다.

---

## Global Context
| Variable | Description | Example / Default |
|----------|-------------|-------------------|
| `{{MODE}}` | `OUTLOOK` / `MIDCHECK` / `REVIEW` 중 하나. 미지정 시 오늘 요일로 자동 판별(일→OUTLOOK, 수→MIDCHECK, 금→REVIEW). 그 외 요일에 실행되면 사용자에게 MODE를 명시적으로 확인하세요. | `OUTLOOK` |
| `{{RUN_DATE}}` | 워크플로우 실행일, YYYY-MM-DD | `2026-08-30` |
| `{{TARGET_WEEK_START}}` | 대상 주의 월요일 날짜, YYYY_MM_DD. `OUTLOOK`은 **다음 주** 월요일, `MIDCHECK`/`REVIEW`는 **이번 주**(이미 가이드가 발행된 주) 월요일 | `2026_08_31` |
| `{{OUTPUT_DIR}}` | 리포트 저장 기본 디렉토리 경로 | `reports/weekly_outlook/` |
| `{{REPORT_PATH}}` | 이 워크플로우가 다루는 유일한 산출 파일 경로 | `{{OUTPUT_DIR}}weekly_guide_{{TARGET_WEEK_START}}.md` |

## 공통 원칙 (모든 MODE 공통)
1. **파일은 한 주에 하나, 계속 이어 쓴다.** 신규 파일 생성은 `OUTLOOK`에서만 하고, `MIDCHECK`/`REVIEW`는 기존 파일을 Read한 뒤 해당 섹션을 새로 추가(Edit)하며 이전에 쓰인 섹션은 그대로 보존한다.
2. **리포트 최상단에 진행 상태 트래커를 두고 매 실행마다 갱신한다:**
   `> **진행 상태:** 전망 완료(YYYY-MM-DD) | 중간점검 완료(YYYY-MM-DD)/예정 | 복기 완료(YYYY-MM-DD)/예정`
3. **"예상 결판 시점" 태그(1주 / 1개월+)를 계속 사용한다.** 단기 모멘텀·기술적 추천은 "1주", 구조적 테마·밸류에이션 정상화처럼 여러 주에 걸쳐 진행되는 추천은 "1개월+"로 표기하고, `REVIEW`에서 채점 방식을 가른다.
4. **추천일 종가·목표가·손절가(또는 관찰 트리거)는 항상 KRX Open API 실측값**을 사용한다(`src/data/krx_openapi_provider.py`).

## Phase Group A — `MODE=OUTLOOK` (일요일: 전망 및 가이드 작성)

### Phase A1: 다음주 캘린더 및 수급/밸류에이션 데이터 수집
* **Instructions:**
  1. **[우선순위 1] KRX Open API 직접 조회:** `.env`의 `KRX_OPENAPI_SECRET_KEY`로 후보 종목들의 `{{RUN_DATE}}` 직전 확정 거래일 종가·시가총액을 실측값으로 확보하세요(`get_kospi_daily_trade` / `get_kosdaq_daily_trade`). 이 값이 가이드표의 "추천일 종가" 기준값입니다.
  2. **[우선순위 2] `/browser`로 다음주 이벤트 캘린더 확보:** 국내 실적발표·공모주·만기일·배당락일(KIND 등 날짜가 명확한 소스 우선), 해외/매크로(FOMC·금통위·미 경제지표 — 정기 발표 규칙은 캘린더 계산으로 먼저 도출 후 검색으로 교차확인), 미국 빅테크 실적 일정.
  3. **최근 수급·모멘텀 스크리닝:** 최근 1주 외국인/기관 순매수 상위 종목, 최근 발간된 섹터 리포트(`reports/sector/`)의 Top-pick·Value-pick을 후보 유니버스로 활용하세요.
  4. **밸류에이션·리스크 체크:** 후보 종목들의 실적 서프라이즈/쇼크 여부, 컨센서스 목표주가, 주가 위치(52주 고점/저점, 이동평균선 배열)를 확인하세요.
  5. **이월 종목 확인:** 직전 주 파일(`{{OUTPUT_DIR}}weekly_guide_{직전주_월요일}.md`)이 존재하면 그 복기 섹션을 읽어, "진행중(carry-forward)"으로 남은 1개월+ 종목이 있는지 확인하세요.

### Phase A2: 다음주 시나리오 및 종목별 투자 판단
* **Instructions:**
  1. **매크로 시나리오 3분기:** 긍정/중립/부정 3가지 시나리오와 각 발생 조건을 제시하세요.
  2. **종목별 매수/매도/관망 판단:**
     - **추천 의견:** 매수 / 매도(비중축소) / 관망
     - **목표가/손절가 (의견별 의미 구분):** 매수=목표가·손절가(-6~-12% 차등), 매도=하락목표가·재검토선(반등 시), 관망=목표가·손절가 대신 **관찰 트리거 레벨** 1개(예: "○○원 이상 돌파 시 매수 전환 검토")
     - **확신도:** 상/중/하 (여러 근거가 겹칠 때만 "상")
     - **예상 결판 시점:** 1주 / 1개월+
     - **추천 근거:** 1~2문장, 반증 가능한 구체적 사실 기반
  3. **관망/제외 사유 명시:** 후보였으나 최종 제외한 종목의 판단 근거도 짧게 남기세요.

### Phase A3: 리포트 최초 생성
* **Instructions:**
  1. `{{REPORT_PATH}}`에 새 파일을 작성하세요. 구조:
     - **진행 상태 트래커** (공통 원칙 2번)
     - **Executive Summary:** 다음주 시황 한 줄 + 핵심 시나리오 3가지
     - **다음주 주요 일정 캘린더:** [날짜 | 이벤트 | 예상 영향]
     - **★ 종목별 투자 가이드표 (핵심, 숫자 중심 — 반드시 실제 표 형식):** [종목명(티커) | 시장 | 추천 의견 | 추천일 종가 | 목표가 | 손절가 | 확신도 | 예상 결판 시점]. **"추천 근거"는 이 표의 열에 넣지 말고**, 표 바로 아래 "### 종목별 추천 근거" 섹션에 종목당 1~2문장 불릿으로 분리하세요 — 근거 문장을 표 셀에 욱여넣으면 표가 지나치게 넓어져 가독성이 떨어집니다.
     - **◆ 이월 종목 추적 (있는 경우만):** Phase A1-5에서 확인한 직전 주 "진행중" 종목을 여기 나열(추천일 종가는 원래 값 유지, 현재가는 이번 주 시점 갱신)
     - **시나리오별 대응 전략**
     - **리스크 요인 및 관망 종목 노트**
     - `## 중간 점검`, `## 복기 결과` 섹션은 **아직 만들지 않는다** — 수요일/금요일에 각각 추가됨을 알리는 한 줄만 남겨둔다: `*(수요일 /weekly-guide MODE=MIDCHECK, 금요일 /weekly-guide MODE=REVIEW 실행 시 이 아래에 섹션이 추가됩니다.)*`

### Phase A4: 복기 가능성 검증 및 완료 브리핑
* **Instructions:**
  1. ★ 종목별 투자 가이드표의 모든 행에 "추천일 종가"와, 의견에 맞는 판정 기준값(목표가·손절가 또는 관찰 트리거)이 채워졌는지 확인하세요.
  2. 추천 의견 비중이 한쪽으로 쏠려 있지 않은지 점검하세요.
  3. 결과 파일 경로와 함께 **'이번 주 가장 확신도 높은 매수 추천 1건'**을 요약해 반환하고, 수요일 `MODE=MIDCHECK`·금요일 `MODE=REVIEW` 실행을 안내하세요.

## Phase Group B — `MODE=MIDCHECK` (수요일: 경량 중간 점검)

> **원칙:** 새 종목을 추가하거나 기존 추천 방향을 뒤집지 않는다. 목적은 (1) 목표가 조기 도달 종목의 조기 익절/트레일링 스탑 상향, (2) 손절가 근접·이탈 종목 조기 경고, (3) 관망 트리거 발동 포착뿐이다.

### Phase B1: 기존 리포트 로드
* **Instructions:**
  1. `{{REPORT_PATH}}`를 Read하세요. **파일이 없으면** "이번 주 가이드가 없어 중간 점검을 진행할 수 없습니다"라고 알리고 중단하세요.
  2. 이미 `## 중간 점검` 섹션이 있다면(중복 실행) 사용자에게 알리고 스킵하세요.
  3. ★ 종목별 투자 가이드표에서 종목명·추천일 종가·추천 의견·목표가·손절가·예상 결판 시점을 추출하세요.

### Phase B2: 실제 가격 확인
* **Instructions:**
  1. `get_kospi_daily_trade` / `get_kosdaq_daily_trade`로 월·화(가능하면 수요일 장중까지) 종가를 조회하세요.
  2. 종목별로 추천일 종가 대비 변동률, 목표가·손절가까지 남은 거리(%)를 계산하세요.
  3. 가능한 범위에서 장중 고가/저가로 목표가·손절가를 스쳤는지도 확인하세요.

### Phase B3: 상태 판정 및 섹션 추가
* **Instructions:**
  1. 각 종목을 🎯목표가 조기 도달 / ⚠️손절가 근접·이탈 / 🔔관망 트리거 발동 / ✅정상 진행중 중 하나로 분류하세요. "1개월+" 태그 종목은 세세한 %p 추적 대신 스토리를 깨는 뉴스가 나왔는지만 가볍게 확인하고 "진행중" 유지하세요.
  2. `{{REPORT_PATH}}`를 Edit하여, ★ 종목별 투자 가이드표(및 이월 종목 추적 섹션) 뒤, 시나리오별 대응 전략 앞에 다음 섹션을 삽입하세요:
     - **## 중간 점검 (수요일, `{{RUN_DATE}}`)**
     - Executive Summary 2~3문장(목표가 조기 도달 N건, 손절 경고 N건 등)
     - **★ 종목별 상태표 (숫자 중심):** [종목명 | 추천 의견 | 추천일 종가 | 현재가 | 변동률 | 상태]. "대응 제언"은 표 열에 넣지 말고 아래 상세 설명에서 다루세요.
     - 조치가 필요한 종목(🎯/⚠️/🔔)만 1~2문장씩 상세 설명(대응 제언 포함)
  3. 진행 상태 트래커를 갱신하세요.

### Phase B4: 검증 및 완료 브리핑
* **Instructions:**
  1. 변동률 계산을 재검산하세요.
  2. 결과 파일 경로와 함께 **'가장 시급한 조치 1건'**을 요약해 반환하세요(없으면 그 사실도 명시).

## Phase Group C — `MODE=REVIEW` (금요일: 복기)

### Phase C1: 기존 리포트 로드 및 검증 대상 확정
* **Instructions:**
  1. `{{REPORT_PATH}}`를 Read하세요(전망 섹션 + 있다면 중간점검 섹션 포함). **파일이 없으면** 중단하고 소급 생성하지 마세요(사후확증편향 방지).
  2. ★ 종목별 투자 가이드표와 ◆ 이월 종목 추적 섹션에서 판정 대상을 모두 추출하세요. "추천일 종가"가 없는 행은 복기 대상에서 제외하고 사유를 명시하세요.
  3. 중간 점검 섹션이 있다면, 주중 조기 도달·경고 정보를 참고하세요(금요일 스냅샷만으로는 놓칠 수 있는 주중 변동 보완용).

### Phase C2: 실제 주가 데이터 수집
* **Instructions:**
  1. `get_kospi_daily_trade` / `get_kosdaq_daily_trade`로 `{{RUN_DATE}}`(금요일) 직전 확정 거래일 종가를 조회하세요.
  2. 동일 기간 KOSPI/KOSDAQ 지수 등락률도 조회해(`get_kospi_index_daily` / `get_kosdaq_index_daily`) 벤치마크 대비 초과수익률을 계산하세요.
  3. 가능하면 일별 고가/저가로 장중 목표가/손절가 터치 여부도 확인하고, 어려우면 종가 기준으로 판정하며 그 사실을 명시하세요.
  4. KRX API로 확보하지 못한 개별 이벤트(실적 발표 결과, 뉴스 촉매)는 `/browser`로 보완하세요.

### Phase C3: 적중 판정 및 원인 분석
* **Instructions:**
  1. **"예상 결판 시점" 태그로 채점 대상을 먼저 분리하세요:**
     - **1주 태그:** 정량 판정을 그대로 적용해 이번 주 안에 적중/실패를 확정합니다.
     - **1개월+ 태그:** 이번 주에 목표가/손절가에 **실제로 도달한 경우만** 확정하고, 그렇지 않으면 "진행중(carry-forward)"으로 표기해 승률 집계에서 제외하고 다음 주 파일의 ◆ 이월 종목 추적으로 넘기세요.
  2. **("1주" + 이번 주 도달한 "1개월+") 종목별 정량 판정:**
     - 실제 수익률(%) = (금요일 종가 - 추천일 종가) / 추천일 종가 × 100
     - 초과수익률(%) = 실제 수익률 - 동기간 벤치마크 등락률
     - 방향 적중 여부: 매수=상승 및 목표가/손절가 중 먼저 도달한 쪽, 매도=하락(또는 벤치마크 대비 underperform) 및 하락목표가/재검토선 도달 여부, 관망=관찰 트리거가 실제 발동했는지(미발동=적중, 발동했는데 대응 안 했으면 "기회비용 발생")
  3. **전체 성적 집계:** 승률("진행중" 제외), 평균 수익률, 평균 초과수익률, 확신도별(상/중/하) 승률 차이.
  4. **잘된 예측 Best 1~2, 틀린 예측 Worst 1~2 및 원인:** 원인은 예상 못한 외부 이벤트 / 확산 속도·강도 오판 / 애초 근거 빈약 / 벤치마크(시장 전체) 요인 중 분류.

* **Instructions:**
